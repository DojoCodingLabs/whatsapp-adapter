## Changelog since 2026-09-01

**Cloud API changelog (CL).** The official page shows no entries after May 12, 2026, and that is the only content I could fetch. A third-party tracker reports these (UNVERIFIED):

- 2026-10-14: Direct Send auth OTP gains copy-code, one-tap and zero-tap. SDK impact: none (Direct Send isn't modelled).
- 2026-10-30: WebP accepted for image messages. SDK already gates webp as a 5 MB image.
- 2026-11-02: Calling API accepts a Messaging account. Out of scope.

**Account model evolution (AME, official).**

- 2026-09-23 to mid-Oct 2026: Messaging accounts are GA. WABA ID == Messaging account ID.
- `paid_messaging_account_id` must be migrated by 2026-12-31.
- `messaging_account_id` becomes required for multi-Messaging-account tokens in H1 2027 and in all versions in H1 2028.
- WAAC IDs replace phone-number IDs in H1 2028.
- SDK impact: add an optional `messagingAccountId` and plan for WAAC.

**Pricing (PR/NT, official).**

- 2026-10-01: service messages are charged per message (1,000 free per phone number per month per PR), and in-window utility templates are charged.
- WABAs with no payment method by 2026-09-30 have had service messages stopped (error 131042, unmapped).
- 2026-08-01: Meta Business Agent is charged at $2 per 1M tokens.
- Status `pricing.subtype` (`free_tier` / `paid_exempt`) and `free_group_customer_service` exist. The SDK surfaces neither.

**Marketing Messages API changelog (MMC, official).**

- 2026-08-05 to 2026-10-19: max-price rollout. The open beta started 2026-10-01; a new error 131065 arrived 2026-10-05; billing SKU 2026-10-15.
- 2026-09-24: template-routing guidance for category mapping and endpoint selection.
- 2026-11-20: from March 2027, error 131066 replaces 131049 for quality or max-price non-delivery.
- MM overview: Cloud API marketing sunset on **2027-10-13**. New accounts created on or after **2027-04-13** can't send marketing via Cloud API.

**Graph API (V/V26).** v26.0 (2026-07-29) is still the latest; no v27 is announced. Nothing WhatsApp-specific changed.
