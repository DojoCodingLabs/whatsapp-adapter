SDK: `packages/whatsapp-sdk @ 177527c` (Graph v26.0). Audit date: 2026-11-26. Read-only audit.

Doc base: `https://developers.facebook.com/documentation/business-messaging/whatsapp/` (shortened to `…/` below). The quotes came from WebFetch, which returns pages through a summarizing model. Short quoted strings are reliable, but check the exact wording on the live page before citing it externally. **UNVERIFIED** marks a claim that rests on memory or that no fetched page confirmed.

Pages that could not be read: `…/calling/voice-call-button-messages` returned only navigation, a login wall or a client-rendered shell, so the voice-call button limits are UNVERIFIED.
